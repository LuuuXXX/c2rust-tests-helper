# c2rust-tests-helper

A test-migration workflow tool for [`c2rust-demo`](https://github.com/LuuuXXX/c2rust-demo) feature
workspaces. It reads `migration.yml` and `.c2rust/<feature>/...` to manage, validate, and execute
the migration of C tests to Rust.

## Core capabilities

| Command | Description |
|---|---|
| `surface` | Print the feature surface (selected files, modules, symbols) |
| `collect` | Discover C tests and merge them into `migration.yml` |
| `lint` | Validate manifest entries against the loaded feature surface |
| `report` | Show migration progress and coverage/gap summary |
| `check` | Run lint, then execute configured test suites, then print a summary |

## Core inputs

| Input | Description |
|---|---|
| `migration.yml` | Central manifest: config, discovery rules, and test-entry table |
| `.c2rust/<feature>/...` | Feature workspace generated by `c2rust-demo` (selected files, modules, symbols) |

## Recommended workflow

```bash
# 1. Inspect the generated feature surface.
c2rust-tests-helper surface --config migration.yml

# 2. Discover C tests and populate migration.yml.
c2rust-tests-helper collect --config migration.yml

# 3. Edit migration.yml – fill in module/symbols/rust_tests mappings.
$EDITOR migration.yml

# 4. Validate edits against the feature surface.
c2rust-tests-helper lint --config migration.yml

# 5. Review migration progress and gaps.
c2rust-tests-helper report --config migration.yml

# 6. Run lint + all configured test suites.
c2rust-tests-helper check --config migration.yml
```

## Configuration example

```yaml
version: 1

project:
  root: ../c2rust-demo
  feature: default

feature_source:
  kind: c2rust_feature
  root: ../c2rust-demo/.c2rust/default

test_commands:
  c: "make test"
  rust: "cargo test"
  feature_rust: "cargo test --features default"

discovery:
  paths:
    - tests/c
  extensions:
    - c
  patterns:
    - regex: 'void\s+(test_\w+)\s*\('
      framework: custom

tests:
  - c_test: test_add
    source_file: tests/c/math.c
    status: ported
    module: mod_math
    symbols:
      - add
    rust_tests:
      - test_add_ported
```

A ready-to-edit sample is included in the repository as [`migration.yml`](./migration.yml).

## Current boundaries

**What this tool does:**
- Manifest management (`migration.yml` read/write, schema validation)
- Feature-surface validation (selected files, modules, symbols from `.c2rust/<feature>/...`)
- Coverage and gap reporting
- Test execution orchestration (lint gate → run `test_commands.*` → unified summary)

**What this tool does not currently do:**
- Automatic test→module/symbol inference
- Rust AST analysis
- Historical result caching
- JSON/JUnit reporting
- Parallel test execution
